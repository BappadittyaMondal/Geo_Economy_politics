## 1. THE 5-STATE CAPABILITY MATURITY MODEL

Every analytical engine and lens in `Geo_Economy_politics` operates in one of five distinct lifecycle states:

```
┌──────────────────────────────────────────────────────────────────────────────────┐
│ DESIGNED         : Mathematical model, clamping equations & logic defined.       │
│ IMPLEMENTED      : Executable Python code compiled and passing syntax checks.    │
│ TESTED           : Machine-verified by automated pytest regression harness.      │
│ EVIDENCE-CONN.   : Connected to live, verified, non-degraded telemetry feeds.    │
│ RELEASE-ELIGIBLE : Hardened against rate-limits, concurrency, and security leaks.│
└──────────────────────────────────────────────────────────────────────────────────┘
```
