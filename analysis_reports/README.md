## Operating Protocol for New Reports
Whenever a new forensic deconstruction or case study is completed:
1. Compile the publication-grade PDF using ReportLab with custom palette, table formatting, and running headers/footers.
2. Save the primary copy directly into `analysis_reports/` using the format `YYYY-MM-DD_HHMMIST_<DESCRIPTIVE_TITLE>.pdf`.
3. Mirror a copy to the active conversation artifact directory for instant UI and browser access.
4. Update this `README.md` table with the new entry, date, description, and file size.
